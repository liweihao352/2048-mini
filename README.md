# 🎮 原神风格 2048

一个网页版 2048 游戏，支持**朴素**和**原神**双主题。原神主题下，数字方块化为提瓦特角色立绘，配元素氛围背景与合并粒子特效。

![主题](https://img.shields.io/badge/主题-原神/朴素-blue) ![协议](https://img.shields.io/badge/代码-MIT-green) ![素材](https://img.shields.io/badge/素材-非官方同人-orange)

## ✨ 特性

- **双主题切换**：朴素（经典 2048 配色）/ 原神（角色立绘 + 元素背景）
- **11 位角色**：数字 2–2048 映射原神角色，按元素色系排序（冰→雷→火→草→岩→风→水）
- **合并特效**：原神模式下合并触发元素色粒子爆发
- **操作**：方向键 / 触屏滑动
- **持久化**：localStorage 保存最高分与主题选择
- **纯前端**：无后端、无依赖、无构建步骤，单文件即用

## 🚀 本地运行

直接用浏览器打开 `index.html`，或起本地服务：

```bash
# 任选其一
python -m http.server 8080
npx serve
```

访问 `http://localhost:8080/`。加 `?demo` 参数可查看全部方块的展示模式：`http://localhost:8080/?demo`

## 🛠 技术栈

- 纯 HTML / CSS / JavaScript（无框架、无构建）
- Canvas 2D 粒子特效引擎
- CSS 变量驱动主题切换
